# Task 0 — Python Fundamentals, Data Analysis & Git

**Name:** Devansh Dixit

## Description
Solutions for IEEE AI/ML SIG Task 0. Covers core Python (lists, functions,
for-else), NumPy vectorized operations, Pandas CSV analysis, and Matplotlib
visualizations.

- `q1.py` — List analyzer (max/min/sum/counts/reverse) without built-ins.
- `q2.py` — `process_list()` demonstrating `.copy()` vs direct assignment.
- `q3.py` — Prime checking using `for-else`.
- `q4.py` — NumPy array basics: shape, dtype, mean/max/min/std, Boolean indexing.
- `q5.py` — Pandas analysis of `student_performance.csv`, saves
  `processed_student_performance.csv`.
- `q6.py` — Matplotlib visualizations built from the processed CSV, saved to `plots/`.

## Setup
```bash
python3 -m venv venv
source venv/bin/activate       # on Windows: venv\Scripts\activate
pip install numpy pandas matplotlib
```

## Running
Q1–Q3 prompt for input on the command line:
```bash
python3 q1.py
python3 q2.py
python3 q3.py
```

Q4–Q6 must be run in order, since Q5 generates the processed CSV that Q6 reads:
```bash
python3 q4.py
python3 q5.py
python3 q6.py
```

Outputs:
- `data/processed_student_performance.csv` (generated by `q5.py`)
- `plots/final_scores.png`, `plots/study_vs_score.png`,
  `plots/score_distribution.png`, `plots/custom_plot.png` (generated by `q6.py`)
